# Open Shortest Path First (OSPF) Deep Dive

**OSPF (Open Shortest Path First)** is an open standard Interior Gateway Protocol (IGP) operating at Layer 3 using IP protocol number 89. It is built on Edsger Dijkstra’s Shortest Path First (SPF) algorithm to calculate loop-free, optimal routes within an autonomous system.

## Link-State Operation & Areas
OSPF establishes a hierarchical network topology centered around **Area 0 (The Backbone Area)**:
- **Routers in OSPF:**
  - **Internal Router (IR):** All interfaces reside in the same non-zero area.
  - **Area Border Router (ABR):** Interfaces connect Area 0 to one or more non-zero areas. Generates Type 3 Summary LSAs.
  - **Autonomous System Boundary Router (ASBR):** Injects external routes (via BGP, static routes, or RIP) into OSPF using Type 5 External LSAs.

## Core LSA Types
1. **Type 1 (Router LSA):** Generated by every router, describing directly connected links within its area.
2. **Type 2 (Network LSA):** Generated by the Designated Router (DR) on broadcast multi-access segments.
3. **Type 3 (Network Summary LSA):** Advertised by ABRs into other areas to describe inter-area networks.
4. **Type 4 (ASBR Summary LSA):** Advertised by ABRs to inform other areas of the metric to an ASBR.
5. **Type 5 (AS External LSA):** Generated by ASBRs describing external redistributed destinations.
6. **Type 7 (NSSA External LSA):** Injected within Not-So-Stubby Areas and converted to Type 5 by the ABR.

## Metric Calculation & Timers
- **Cost Calculation:** `Cost = Reference_Bandwidth / Interface_Bandwidth`. For modern gigabit/10G links, `auto-cost reference-bandwidth 10000` or higher must be configured across all routers to avoid equal cost metrics for 100M and 10G interfaces.
- **Hello & Dead Timers:** Typically 10s Hello / 40s Dead on broadcast media. Hello/Dead timers and area IDs must match for neighbor adjacency to transition from `Init` -> `2-Way` -> `ExStart` -> `Exchange` -> `Loading` -> `Full`.
